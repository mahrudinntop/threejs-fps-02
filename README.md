**Ashgrove Yard** — a round-based tactical FPS in three.js. 5v5 rounds on a walled yard map: attackers plant a charge, defenders stop it. Nine rounds, credits economy, bot squadmates with A* pathing, hitscan weapons with recoil and headshot multipliers, buy-free loadout escalation, and a live HUD with kill feed, objective banner and round score.

## Run it

```sh
npm install && npm run dev
```

Then open the printed local URL and click the canvas to capture the pointer.
